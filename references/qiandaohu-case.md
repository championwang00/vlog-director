# 案例：千岛湖 GO 野 25K · 还跑（2026-11-21 至 11-25）

## 概况
- **素材**：63 份，其中视频 47 段（原长合计 7 分 13 秒）、照片 16 张；后来补了 5 段 Live 视频和 2 张场地照片。两天：11/21 领物日、11/22 比赛日。
- **音乐**：Coldplay & Tove Lo《Fun》，136 BPM。用户最先给的是 .ncm 加密文件，被拒绝转换后换了无加密文件。
- **成片**：竖屏 1080×1920、30fps，约 3:05，61 个镜头，29 句旁白（用户自己录），85 处包装。
- **工具**：GPT 理解素材 → Claude（Opus）写剧本和分镜预演 → Codex CLI（gpt-6.2-sol）在剪映专业版 11.7/11.8 里执行，共 11 轮 → Claude 审片。
- **交付**：剪映草稿「11月25日」、preview_v1…v9、旁白录音清单、封面「完赛但膝盖废了」（3:4）、小红书标题和正文。项目结束后，用户要求删掉素材和工程，封面和录音清单留在「下载」文件夹。

## 故事线（用户原话的要求）
开心参赛 → 遇到髂胫束疼痛 → 坚持下来 → 简单复盘 → 「下次还来跑吗？」画面一黑 →「还跑」。

## 迭代时间线（用户反馈 → 改动）
1. 剧本文字版 → 「没法看」→ 做成可播放的分镜预演。
2. 加「还有 2 公里」进钩子；钩子压到 3 秒内。
3. 画外音要有艺术感、哲理和励志感 → 立主题句、结尾回收。
4. 开场太简单 → 加身份、ITRA、旧伤、目标的填空。
5. 音乐：低谷过渡、冲线不够激昂、收尾渐强、三次修断点 → 最后改成两轨叠化、高能量处不切。
6. 加「忘填编号，第二枪，晚 20 分钟」；补 CP1、CP2 到站画面（用 Whisper 从风噪里听出「CP2，CP2」）。
7. 交给 Codex；同时做 33–36 抠像 + 运动模糊（修方向、修脚）→ 直接给成品图。
8. 包装 61 → 85 处；照片展示从「烧边」改成「缩小放黑底、四边留黑」；撤掉所有滤镜。
9. Live 照片：查明素材里没有 Live 视频 → 用户导出原件 → 先动后定格。
10. 复盘改成起跑开头、冲线结尾；名字墙只留人；吉祥物加回来；开场顺序调整。
11. 开场冒出「三」→ 逐字定位，入点改到 3.62 秒。
12. EVA 式大字卡（详见 eva-typography 技能）；加「比赛日 / 三十五分钟前」呼应「领物日」。
13. 克隆音色朗读超时 → 用户决定自己录 → 交付录音清单。
14. 倒带画面、现场环境声、人声增强（用会员的人声美化）。
15. 封面、标题正文；清理文件。

## Codex 执行中遇到的问题
- 第一次接续没写 `-m`，跑成了默认模型，立刻中断重来。
- 磁盘只剩 1 GB，剪映报磁盘不足、Vision 抠像失败。
- 台前调度把剪映缩成 92×112 的缩略图，Codex 点不到；用 `open -a` 解决。
- Mac 锁屏，Codex 停住；用户解锁后继续。
- 草稿两处退回旧版本；打码视频没音轨；人声增强漏一段。
- Codex 绕开会员功能，改在外部处理人声；用户说明自己是会员后，改用剪映自带的人声美化。
